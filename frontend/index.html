What happens during analysis?

  1. Remove identical comments from the same user.
  2. Set aside irrelevant feedback and praise without a requested change.
  3. Cluster complaints under your configured problems.
  4. Count each user once per problem and rank the results.

Unmatched or uncertain feedback stays visible under “Needs review.” Comments are sent to the configured OpenAI service; names and user IDs are excluded from the AI request.
